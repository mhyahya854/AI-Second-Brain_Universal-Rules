This 18-stage, 180-Markdown-file repository (`103` populated files and `77` reserved zero-byte lifecycle topic files, structurally reorganized without rule loss from `MASTER_PLAN.md`) contains the current candidate constitution, application planning/execution instructions, Green/Red/Fix procedure, historical preservation map, and technical research evidence. Its purpose is durable, user-owned, understandable, recoverable, portable, maintainable software with truthful evidence and bounded authority. It improves the probability of long-term usefulness without promising indefinite operation or flawless AI execution.

**Two different repository contracts:** the active **Universal Rules** tree is organized into 18 numbered lifecycle folders (`0- Start Here and Universal Rules` through `17- Preserving Memory and Learning`) containing 10 numbered Markdown files per stage (`180` files total: `103` populated files and `77` reserved zero-byte topic files), with the prior single-file `MASTER_PLAN.md` baseline preserved in Git history. Future **application** repositories use the separate multi-folder planning and Codebase blueprint in [section 39](../6-%20Writing%20the%20Complete%20Master%20Plan/608-%20Finalizing%20the%20Project%20Folder%20Structure.md#s39). Application folders shown in section 39 are instructions for future products, not folders in this constitutional repository. Git metadata is not a tracked constitutional file.

**NO FALLBACKS IN THE APP PLAN OR CODEBASE:** selected implementations fail honestly; [section 37](002-%20The%20Universal%20Constitution.md#s37) preserves explicit recovery, same-operation retries, independent local functionality, and deliberate platform/migration contracts without hidden substitution.
