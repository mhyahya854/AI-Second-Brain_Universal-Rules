### 41.4. EXEC-4 — Project State and a bare “Continue” request

**Type:** ECOSYSTEM POLICY | **Origin:** USER POLICY | **Applies:** every active application and new-session continuation

The concise Project State required by [DEV-9](../17-%20Preserving%20Memory%20and%20Learning/1701-%20Recording%20Current%20Project%20State.md#dev-9) MUST expose current phase/subphase; last verified completed phase/subphase; completed capabilities; work in progress and not started; actual implementation status; known blockers and important unresolved errors; applicable observed repository revision and relevant dirty state; next authorized action; phase/subphase paths; and continuation instructions. Its human-readable and machine-readable representations MUST agree; one structured Markdown record may serve both. Do not invent the future commit that will contain a state update.

On receiving only **“Continue,”** an executor MUST read repository entry instructions (`AGENTS.md` and [001- How to Use This System.md](001-%20How%20to%20Use%20This%20System.md)) and Project State, reestablish mandatory always-on **Ponytail** and **Unlazy** operating layers and conditional **Graphify** evaluation under [SKILL-1](006-%20Global%20Skills%20and%20Always-On%20Rules.md#skill-1) and [SKILL-2](../8-%20Dividing%20the%20Project%20Into%20Executable%20Steps/806-%20Selecting%20Compatible%20Skills%20for%20Each%20Task.md#skill-2), reconcile them against actual files/revision/evidence, locate the first unfinished authorized phase and its first unfinished subphase, load its full contract, and inspect existing partial work before acting. A partial subphase MUST NOT automatically restart from scratch. After passing its gate, the executor MAY continue to the next ordered authorized subphase in the same session. Existing delegation persists; “Continue” does not grant new production, destructive, credential, or other ungranted authority. If observed state contradicts recorded state, reconcile evidence and authorization before proceeding; do not select an easier later task.
