### 33.4. SKILL-4 — Universal workflow capability catalog

**Type:** ECOSYSTEM POLICY | **Origin:** USER POLICY | **Applies:** ecosystem Agent Skill Library scope and design of the listed reusable workflows

The library blueprint MUST support the following logical workflow families, with discoverable purpose, procedure, inputs/outputs, evidence, validation, and stopping conditions appropriate to each. Implementations MAY combine closely related workflows or split large ones while preserving focused responsibilities; neither one file per row nor loading every family for every task is required. Applicable project contracts remain primary under [SKILL-2](../8-%20Dividing%20the%20Project%20Into%20Executable%20Steps/806-%20Selecting%20Compatible%20Skills%20for%20Each%20Task.md#skill-2). Availability, implemented/reviewed status, and limits MUST be reported honestly rather than treating this policy catalog as installed trusted packages.
